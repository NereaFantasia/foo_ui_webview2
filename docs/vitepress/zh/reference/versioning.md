# 版本与兼容性

自 2.0.0 起，foo_ui_webview2 遵循[语义化版本](https://semver.org/lang/zh-CN/)。版本号格式为「主版本.次版本.修订号」：次版本新增功能，修订号修复问题，破坏性变更只出现在主版本中。

## 2.x 的兼容性承诺

- 已有的方法、事件、参数与返回字段不会被移除、改名或改变类型。
- 可选参数不会改为必填；同一情形下返回的错误码保持不变。
- 新功能以新增方法、事件、参数或字段的形式提供。
- 破坏性变更只在下一个主版本（3.0.0）中发布，更新日志会列出迁移方法。
- 行为与文档不符的问题按文档修复。这类修复不视为破坏性变更，但会在更新日志中单独标出。

## 弃用

标为弃用的接口在整个 2.x 内保持可用，下一个主版本才会移除。SDK 类型以 `@deprecated` 标注，文档注明替代方式。

## 实验性接口

在文档与 SDK 类型（`@experimental`）中标为实验性的接口不受上述承诺约束，可能在次版本中变更，变更会写入更新日志。

## 版本对应

- SDK（`foo-webview-sdk`）与插件的主版本一致，2.x 的 SDK 用于 2.x 的插件。
- 新增的接口在文档中注明首个可用版本。主题可通过 `config.getVersionInfo()` 返回的 `plugin.version` 判断当前宿主是否支持。
- 宿主会拒收未声明的参数：较旧的 2.x 宿主收到它不认识的参数时，调用以 `INVALID_PARAMS` 失败，不会静默忽略。
- MCP 服务器（`foo-ui-webview2-mcp`）独立编号，0.x 期间不作兼容性承诺。

## 1.x

1.x 系列的最终版本为 v1.14.0，此后不再提供任何更新，包括安全修复。1.x 对页面来源的校验不完整，详见[更新日志](/zh/changelog)中 v1.14.0 的已知问题。仍在使用 1.x 的主题，请参阅更新日志中 v2.0.0 的破坏性变更完成迁移。
