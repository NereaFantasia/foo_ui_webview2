# 版本与兼容性

自 2.0.0 起，foo_ui_webview2 遵循[语义化版本](https://semver.org/lang/zh-CN/)规范。版本号采用 `主版本.次版本.修订号` 结构：次版本引入向下兼容的新功能，修订号提供向下兼容的问题修复，破坏性变更仅在主版本变更时引入。

## 2.x 兼容性承诺 {#_2-x-的兼容性承诺}

- 既有方法、事件、参数与返回数据结构字段不会被移除、重命名或变更数据类型。
- 可选参数绝不会变更为必填项；相同调用场景下返回的错误码保持严格恒定。
- 新增功能均以新增独立方法、事件、可选参数或响应字段的形式递增提供。
- 破坏性变更仅在下一个主版本（3.0.0）中发布，并在更新日志中提供详细的迁移指引。
- 运行行为与文档契约不一致的问题按文档事实修复。此类缺陷修复不属于破坏性变更，但会在更新日志中明确标出。

## 弃用机制 {#弃用}

标为弃用的接口在整个 2.x 主版本生命周期内保持稳定可用，直至下一个主版本才会移除。SDK 类型定义中以 `@deprecated` 标注，文档会说明推荐的替代方案。

## 实验性接口

在文档与 SDK 类型中标记为实验性（`@experimental`）的接口不受上述兼容性承诺约束，可能在后续次版本中发生变更，所有改动均记录于更新日志。

## 版本对应关系 {#版本对应}

- SDK（`foo-webview-sdk`）与宿主插件主版本保持对齐：2.x 版本的 SDK 专用于 2.x 插件。
- 新增接口在文档与类型中注明首发支持版本。主题可通过 `config.getVersionInfo()` 获取 `plugin.version` 检测当前宿主运行时的支持情况。
- 宿主插件严格拒收未声明的参数：较早版本的 2.x 宿主接收到未声明的未知参数时，调用将以 `INVALID_PARAMS` 显式失败，绝不静默忽略。
- MCP 服务端（`foo-ui-webview2-mcp`）采用独立版本管理，在 0.x 阶段不提供长期向后兼容承诺。

## 1.x 历史说明 {#_1-x}

1.x 系列的终结版本为 v1.14.0，后续不再提供任何功能或安全更新。1.x 版本对页面来源的校验机制不完整（详见[更新日志](/zh/changelog)中 v1.14.0 已知问题）。仍运行于 1.x 的主题，请对照更新日志中 v2.0.0 的破坏性变更清单完成平滑迁移。
