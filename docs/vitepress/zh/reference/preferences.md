# 偏好设置

组件首选项配置位于 `File → Preferences → Display → WebView2 UI` 页面及其三个子页面，另有部分高级安全例外设置位于高级首选项分支中。

## WebView2 UI 主页 {#webview2-ui-页}

总览主页面包含三个功能分组：

- **Web 模板**：展示当前全局活动模板及其存放目录。点击 `管理...` 可创建、重命名或删除模板（新模板由用户命名）；点击 `打开...` 可在系统文件管理器中打开对应模板文件夹。
- **外观**：配置组件显示语言（自动 / English / 中文）与默认窗口背景材质效果（如 Mica、Acrylic 或无背景）。语言切换对新打开的组件对话框即时生效；系统菜单项与面板描述文本在重启 foobar2000 后更新。
- **工具**：展示只读的开发服务器运行状态行，并提供跳转至高级设置分支与公开 API 列表的快捷按钮。

## 子页面 {#子页}

首选项左侧导航树包含三个子页面，页面名称跟随组件显示语言并在重启后刷新：

- **窗口**：配置窗口位置与尺寸记忆；后台驻留模式（重启后生效）与启动时恢复后台窗口上次的显示 / 隐藏状态（勾选后台模式后可编辑）；最小化到托盘与关闭到托盘（当前主题尚未创建托盘图标时置灰禁用并附带提示）；任务栏缩略图播放控制按钮（重启后生效）与任务栏图标上的播放进度指示。主题在运行期通过 `tray.*` 或 `taskbar.*` API 设置的属性仅覆盖当前会话，不会回写首选项配置。
- **性能**：配置启动时预热 WebView2 环境（关闭时在首个窗口需要时延迟创建，重启后生效）；主窗口隐藏时深度挂起 WebView（仅对主窗口生效；CDP 保活激活期间不挂起）；默认页面缩放比例（50%–200%，步进 25%，叠加于系统 DPI 缩放之上）。点击 `应用` 后已打开的窗口立即更新缩放（主题显式调用过 `window.setZoom` 的窗口除外），新窗口在创建时直接应用该设定值。
- **开发者**：配置开发者工具 (F12)；开发服务器开关与目标 URL，点击 `应用` 立即热重载主窗口与绑定全局模板的面板（无需重启）；CDP 远程调试开关及其监听端口（范围 1024–65535，默认 9222）。开发者工具、CDP 开关与端口改动均在重启后生效。修改调试端口后，MCP 调试服务亦需同步更新配置（环境变量 `FB2K_CDP_PORT`，详见 [MCP 配置指南](/zh/mcp/setup)）。

## 草稿与持久化 {#草稿与应用}

各页面的所有修改均优先暂存于草稿缓冲区：仅在点击 `应用` 或 `确定` 时才持久化写入磁盘；点击 `重置页面` 仅将当前草稿恢复为默认值而不执行写盘；点击 `取消` 丢弃所有未应用的草稿变更。模板管理（创建、重命名、删除）属于即时生效的文件系统操作，不受 `取消` 操作回滚；当前全局活动模板与被任何运行中面板引用的模板受保护，禁止重命名或删除。

## 高级分支

安全例外配置保留于 `File → Preferences → Advanced → Tools → WebView2 UI` 分支中：包括 CDP 后台会话保活、HTTP 请求访问本地局域网（SSRF 例外）、`fb.http.*` 允许无效 TLS 证书，以及保留的 HSTS 条目。条目名称跟随组件显示语言。后台模式、深度挂起、开发者工具、CDP 调试开关以及开发服务器设置已整合至常规显示首选项；旧版本配置的数值会在首次读取时自动迁移。
