# 安装主题

主题以文件夹形式组织并统一称作「模板」，其根目录下必须包含 `index.html` 入口文件。所有模板集中存放在 `<profile>\webview-ui\` 目录下，由全局活动模板承载主窗口。完整的加载查找逻辑见[页面从哪里加载](/zh/concepts/page-loading)。

## 创建模板与主题文件部署 {#新建模板并把主题复制进去}

1. 打开 `File → Preferences → Display → WebView2 UI`。
2. 单击 `管理...`，选择 `新建...`。输入仅包含字母、数字、`-` 与 `_` 的名称并确认。foobar2000 将创建 `<profile>\webview-ui\<名称>\` 目录，生成基础占位 `index.html`，并在 `模板` 下拉列表中自动选中新模板。
3. 单击 `打开...`，在 Windows 资源管理器中打开该模板目录。
4. 将主题产物复制到该目录中，覆盖初始占位的 `index.html`。若使用前端打包工具构建，复制的是构建输出目录中的内容（例如 Vite 的 `dist/` 内容），而非整个外层目录。
5. 单击 `应用`。主窗口以及所有跟随全局模板的面板将重新加载并呈现新主题。

若模板目录中不存在 `index.html` 或该文件内容为空，`应用` 操作将予以拒绝。

## 在已安装模板之间切换 {#在已安装的模板之间切换}

在 `模板` 下拉列表中选择其他条目并单击 `应用`。模板的新建、重命名与删除操作会即时生效于本地文件系统，无法通过 `取消` 进行撤销；当前处于活动状态的模板以及正在被任何加载面板使用的模板受系统保护，不可重命名或删除。

## 为独立面板指定专属模板 {#只让某个面板用这个模板}

嵌入式面板可脱离全局模板绑定，加载独立的自定义模板，见[把页面放进面板](./panels.md#给面板指定自己的模板或-url)。

## 处于开发服务器模式时的表现 {#开发服务器开着时}

当 `开发者` 页面中勾选了 `使用开发服务器（HMR 热重载）` 时，页面将优先从远程开发服务器加载，此时切换本地模板不会触发重新加载。取消勾选并按 `应用` 后，窗口将切回本地已安装模板。详见[用开发服务器调试主题](./dev-server.md)。
