# 安装主题

主题就是一个带 `index.html` 的文件夹，称为模板。模板都放在 `<profile>\webview-ui\` 下，一个模板一个文件夹，活动模板填满主窗口。完整的查找过程见[页面从哪里加载](/zh/concepts/page-loading)。

## 新建模板并把主题复制进去

1. 打开 `File → Preferences → Display → WebView2 UI`。
2. 按 `管理...`，选 `新建...`。输入只含字母、数字、`-` 和 `_` 的名称并确认。foobar2000 创建 `<profile>\webview-ui\<名称>\`，放入一个占位用的 `index.html`，并在 `模板` 框里选中新模板。
3. 按 `打开...`，在文件资源管理器里打开模板文件夹。
4. 把主题的文件复制进去，覆盖占位的 `index.html`。用打包工具构建的项目，复制的是输出文件夹里的内容（Vite 是 `dist`），不是文件夹本身。
5. 按 `应用`。主窗口和所有跟随全局模板的面板重新加载，显示这个主题。

模板文件夹里没有 `index.html`，或 `index.html` 为空时，`应用` 会拒绝。

## 在已安装的模板之间切换

在 `模板` 框里换一项，按 `应用`。模板的新建、重命名和删除是立即执行的文件操作，`取消` 不会撤销；当前活动模板和已加载面板正在用的模板不能重命名或删除。

## 只让某个面板用这个模板

面板可以不跟随全局模板，加载自己的模板，见[把页面放进面板](./panels.md#给面板指定自己的模板或-url)。

## 开发服务器开着时

`开发者` 页勾选了 `使用开发服务器（HMR 热重载）` 时，页面从开发服务器的地址加载，换模板不会让它们重新加载。取消勾选并按 `应用`，才能看到已安装的模板。见[用开发服务器调试主题](./dev-server.md)。
