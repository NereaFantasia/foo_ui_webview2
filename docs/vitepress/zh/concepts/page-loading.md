# 页面从哪里加载

窗口或面板打开时，组件要决定加载哪个页面。了解这个顺序，就能明白为什么窗口显示的是旧主题、内置测试页，或是 “Frontend not found” 页面。

## 模板

模板是 profile 资源根目录 `<profile>\webview-ui\` 下带 `index.html` 的文件夹。一个主题可以有多个页面、脚本和资源文件，必需的只有 `index.html`。

```text
<profile>/
└── webview-ui/                 资源根目录
    ├── default/                未指定模板时的默认模板
    │   └── index.html
    └── my-theme/               自定义主题模板
        ├── index.html
        └── assets/
```

全局活动模板在 `File → Preferences → Display → WebView2 UI` 偏好设置中指定；未显式配置时默认为 `default`。偏好设置中的「新建模板」仅生成基础 `index.html` 占位文件，不包含 SDK、构建脚本或前端依赖。

本地模板由自定义虚拟源 `https://foo-ui-webview2.local/` 托管并映射到模板根目录：根路径 `/index.html` 对应模板入口文件，`/assets/app.js` 等绝对根路径亦在模板目录内正确解析。

## 查找顺序

主窗口、后台窗口与各 UI 面板依序匹配首个有效资源源：

1. **开发服务器**：启用 `使用开发服务器（HMR 热重载）` 且配置了有效 URL 时，所有窗口与面板优先请求此 URL；连接失败时按后续顺位回退。
2. **面板 URL 覆盖**：若面板配置了独立的 URL 覆盖项，则加载该 URL。
3. **面板专属模板**：面板显式指定独立模板目录，且其下存在 `index.html` 入口文件时加载该模板。
4. **全局活动模板**：偏好设置指定的全局模板目录内存在 `index.html` 时加载该模板。
5. **组件分发目录**：组件安装目录中的 `foo_ui_webview2_resources\dist` 存在 `index.html` 时加载；目录为空或缺少入口文件则自动跳过。
6. **默认模板**：`<profile>\webview-ui\default\` 目录下存在 `index.html` 时加载。
7. **内置回退页面**：上述路径均未匹配时，主窗口与后台窗口加载内置 API 测试页；面板则呈现 “Frontend not found. Please install a template.” 缺省提示。

由 `window.createPopup` 创建的弹出窗口遵循独立的解析规则：直接从当前生效模板目录（或开发服务器）加载指定页面（如 `<page>.html`），并在查询参数中注入 `windowId`；若开发服务器不可达则回退至本地模板对应文件；所有模板文件夹都没有 `index.html` 时，显示 “Frontend not found” 页面。

## 重载触发条件 {#重载触发条件}

页面重载由明确的配置变更与应用操作触发，不同窗口类型的响应规则如下：

- **偏好设置应用**：在首选项中修改活动模板或开发服务器配置并点击 `应用` 后，主窗口以及继承全局模板的面板将立即重载；显式配置了独立模板或 URL 覆盖的面板不受影响。
- **开发服务器优先级**：在开发服务器处于启用状态时，切换活动模板不会触发页面重载，所有视图持续由开发服务器提供。
- **独立面板配置**：在面板属性配置对话框中修改专属模板或 URL 覆盖项并确认后，仅当前面板执行重载。
- **弹出窗口生命周期**：全局偏好设置的变更不会重载当前已存在的弹出窗口；新配置仅对后续新建的弹出窗口生效。
